# Laut Berkah Abadi (LBA) Banyuwangi - Frontend

Direct-to-Consumer Cold Chain Seafood Marketplace berbasis Pelabuhan Muncar, Banyuwangi.

## Tech Stack
- Nuxt 3 / Vue 3
- Tailwind CSS
- Pinia Store
- Google Stitch Design System

## Local Development
```bash
npm install
npm run dev
```

## Vercel Deployment
- **Framework Preset**: Nuxt.js
- **Root Directory**: `./`
- **Build Command**: `npm run build`
- **Output Directory**: `.output`
